# Effect catalog

Generated by `scripts/fx_docs.py` from `scripts/fx_catalog.py`. Demo clip per preset: `gallery/fx/<name>.mp4`.

How the owner asks: "put shake_3 + flash_2 on kill 5", "whip_1 transition after kill 8", "hero speed on kill 1".
In edl.json: `"effects": [{"preset": "shake_3"}, {"preset": "flash_2"}]`, `"transition_out": {"preset": "whip_1"}`,
`"speed": {"preset": "hero"}`, texts `{"preset": "word_pop", "text": "BANG", "beat": 24, "dur": 2}`.
Effect strength is multiplied by the clip's `intensity`.

## Adding a new look

1. Add a preset to `fx_catalog.py` (+ a line in the matching `*_INFO`). A brand-new effect type also needs a branch in `render.py` (`kill_effects` sets a state value, `clip_frame` draws it).
2. From `gallery/`: `python ../scripts/fx_gallery.py --video <recording> --kill <frame> --kill2 <frame> --out . --only <name>`.
3. Run `fx_docs.py` to regenerate this file.
