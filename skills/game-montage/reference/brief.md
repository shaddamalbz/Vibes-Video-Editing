# Brief template

Ask the owner to fill this in at the start. If `<profile_dir>/brief.md` exists, use that version instead: it carries the channel's own defaults. For missing answers use the defaults in brackets and say so.

```
Video: <raw_dir>/[game]/[file]
Game and kind of video: [e.g. shooter kill montage / boss fight / story long-form]
Player: [name or character; whose moments count, e.g. only this player's kills]
Song: [title + link, or a file]                (none for a game-sound-only long-form)
Song part: [e.g. 0:35 to 1:22]                 (default: the agent picks the most exciting 45-60 s)
Important moments in the song: [e.g. the hook word at 0:57 and 1:00]
Lyric words on screen: [typed by the owner, one word per line]   (none if empty: the agent never writes lyrics)
Moments: [all / the best], favourites: [e.g. the chase at 12:40]
Opening: [relaxed / straight into action]      (default: relaxed)
Story: [e.g. intro card -> fight -> biggest hit on the drop -> victory banner]
Text on screen: [none / song words / SFX words / reaction captions]   (default: none)
Length and format: [e.g. 45-60 s, 9:16, 1080p 60 fps / 16:9 long-form]
Effects wanted: [e.g. shake_3 on the drop moment, letterbox_1 on the last one]   (names: reference/effects.md)
Ending: [channel logo card from the profile's brand.json / none]
```

Downloading the song needs the owner's explicit yes (see [song-analysis.md](song-analysis.md)). After the first video, save the owner's usual answers as `<profile_dir>/brief.md`.
